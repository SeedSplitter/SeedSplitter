Creá una wallet fría.
O protegé la que ya tenés.

SeedSplitter concentra en un único dispositivo offline dos tareas distintas: generar una seed nueva sin depender de un RNG interno y crear un backup distribuido 2-de-3 de una seed existente.

01
GENERATE + WATCH-ONLY

Generá tu seed y llevá sólo la zpub al mundo online.

Ingresás 50 tiradas de un dado físico. SeedSplitter genera una frase BIP39 de 12 o 24 palabras y, cuando querés, deriva localmente la cuenta BIP84 y muestra su zpub por QR.

La wallet watch-only puede generar direcciones y seguir saldo y transacciones sin recibir la seed ni las claves privadas necesarias para firmar.

50 tiradas → BIP39 → m/84'/0'/0' → zpub → watch-only
02
SPLIT + RECOVER

Convertí una sola copia crítica en un backup distribuido.

Ingresás tu seed BIP39 y SeedSplitter genera tres seed phrases válidas y distintas. Las guardás en lugares separados y cualquier combinación de dos permite reconstruir la original.

Si el hardware deja de existir, la recuperación también puede hacerse con el script open-source recover.py.

1 seed → 3 backups · cualquier 2 → seed original

// SPLIT + RECOVER

De una seed a tres backups.

El objetivo es evitar que una única copia física sea un punto único de falla. SeedSplitter trabaja con frases BIP39 de 12 o 24 palabras.

01 · INPUT

Ingresás tu seed.

La cargás palabra por palabra usando los tres botones del dispositivo. No hace falta conectarlo a una computadora.

02 · SPLIT

Obtiene tres frases BIP39.

SeedSplitter muestra tres seed phrases válidas y distintas. Cada una puede interpretarse como una wallet BIP39 independiente.

03 · DISTRIBUTE

Las guardás por separado.

Podés elegir ubicaciones y custodios diferentes para reducir el riesgo de pérdida, robo o destrucción de una única copia.

04 · RECOVER

Cualquier par recupera la original.

Ingresás dos de las tres partes y SeedSplitter reconstruye la seed original de 12 o 24 palabras.

La recuperación no depende de conservar el hardware.

El repositorio incluye recover.py para reconstruir la seed original a partir de dos partes.

SeedSplitter está pensado para que las propiedades importantes puedan inspeccionarse: el firmware es público, el hardware está expuesto y el repositorio incluye vectores reproducibles para comprobar el comportamiento.

01

SIN WI-FI NI BLUETOOTH

El diseño no incorpora radios Wi-Fi ni Bluetooth. Las operaciones de generación, división, recuperación y derivación ocurren localmente.

02

SIN PERSISTENCIA DE LA SEED

La seed y las tiradas se procesan en memoria de trabajo; el firmware no las escribe como datos de usuario en almacenamiento persistente.

03

HARDWARE VISIBLE

El microcontrolador, la pantalla y las conexiones quedan físicamente expuestos para facilitar la inspección del dispositivo.

04

CÓDIGO ABIERTO

Firmware, scripts de recuperación y tests están publicados. Podés leer el código, compilarlo y comparar resultados conocidos.

05

ENTROPÍA APORTADA POR VOS

Generate usa 50 tiradas físicas como fuente de entropía. No necesitás confiar en un generador aleatorio interno para crear la seed.

06

TESTS REPRODUCIBLES

El repositorio incluye pruebas de Split, Recover, Generate y exportación watch-only para frases de 12 y 24 palabras.

// USO AVANZADO

Las partes también son wallets BIP39 válidas.

Las tres partes generadas por Split no son cadenas ilegibles: son frases BIP39 válidas. Eso permite, si querés, usar una parte como wallet señuelo o “canary”: asignarle una pequeña cantidad y monitorear sus direcciones para detectar si ese backup fue accedido.

Eso no convierte a la parte en la seed original. Una sola parte no alcanza para reconstruir la wallet protegida; para recuperar la seed original siguen haciendo falta dos de las tres partes.

Esta es una estrategia opcional de monitoreo, no un reemplazo de una política de backups, privacidad y custodia bien diseñada.

// PREGUNTAS FRECUENTES

Lo importante, sin letra chica.

¿Qué es una zpub?
Es una clave pública extendida para una cuenta Bitcoin Native SegWit. Permite derivar las direcciones públicas de esa cuenta y construir una wallet watch-only, pero no contiene las claves privadas necesarias para firmar transacciones.
¿La zpub permite gastar mis bitcoins?
No. La zpub sirve para observar y derivar direcciones, no para firmar. Sin embargo, sí revela información sobre las direcciones y actividad de esa cuenta, por lo que debe tratarse como información sensible desde el punto de vista de la privacidad.
¿Qué derivation path usa la exportación watch-only?
La implementación actual usa Bitcoin mainnet, cuenta 0 y el path BIP84 m/84'/0'/0'. La derivación BIP39 usa passphrase vacía.
¿SeedSplitter soporta BIP39 passphrase en la exportación watch-only?
La versión actual del firmware deriva la zpub con passphrase BIP39 vacía. La página no asume soporte para una passphrase adicional.
¿Qué pasa si pierdo o rompo SeedSplitter?
Si usaste Split, la recuperación de la seed original no depende del hardware: el repositorio incluye recover.py, que reconstruye la original a partir de dos de las tres partes.
¿Qué pasa si pierdo una de las tres partes?
El esquema requiere cualquier combinación de dos partes para reconstruir la seed original. Perder una de las tres no impide la recuperación, siempre que las otras dos sigan disponibles.
¿Las tres partes son seed phrases reales?
Sí. El proyecto genera tres frases BIP39 válidas y distintas. Eso permite abrir cada parte como una wallet BIP39 independiente; una sola parte, sin embargo, no reconstruye la seed original protegida.
¿Necesito conectar SeedSplitter a una computadora?
No para usar Split, Recover o Generate. El dispositivo funciona de manera autónoma. Para watch-only, la transferencia de la zpub se hace visualmente mediante QR hacia una wallet compatible.
¿Por qué 50 tiradas?
Cincuenta resultados independientes de un dado de seis caras contienen aproximadamente 129 bits de entropía teórica (50·log2(6)). El firmware usa esa fuente física para construir la seed BIP39.
¿Cómo verifico que mi unidad funciona correctamente?
Usá los vectores publicados en TEST.md y compará palabra por palabra y, para Generate, también las direcciones BIP84 derivadas desde la exportación watch-only. Las seeds de test nunca deben usarse para guardar fondos.
¿El código y el hardware se pueden auditar?
El firmware y las herramientas auxiliares están publicados en GitHub. El dispositivo además deja visibles sus componentes principales —microcontrolador STM32, pantalla OLED y conexiones— para facilitar su inspección física.
